# character-builder

Скилл для Claude, который помогает собрать внешность виртуального персонажа. Он задаёт вопросы по одному, объясняет варианты простыми словами и в конце выдаёт готовый промпт для любой нейросети, которая генерирует картинки.

Этот скилл разбирали на открытом эфире AI Кэмпа «Свой виртуальный персонаж в 2026 году».

## Как подключить

- **Claude (приложение или claude.ai):** скачай репозиторий архивом (Code → Download ZIP) и загрузи его в разделе Skills в настройках Claude.
- **Claude Code:** положи папку с `SKILL.md` в `~/.claude/skills/character-builder/`.

Потом напиши Claude, что хочешь создать своего персонажа.
